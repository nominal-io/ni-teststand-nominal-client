# ni-teststand-nominal-client

Everything a person reads in this repo follows the Nominal docs hub's writing rules:

@../pub-docs/CLAUDE.md

If that import comes up empty, pub-docs isn't checked out beside this repo. Read
https://github.com/nominal-io/pub-docs/blob/main/CLAUDE.md instead. Its "Building and checking"
and "Repo conventions" sections are about pub-docs itself and don't apply here.

The rules cover more than the docs in `docs/`:
- the README
- the step types' names, in the type palette
- the result plugin's configuration dialog and its messages
- the VIs' descriptions and their inputs' and outputs' descriptions, which the reference shows
- code comments

The user docs quote the steps' names and the plugin's labels word for word, so changing one is a
docs change too. `docs/CLAUDE.md` has the rules for the pages themselves.
